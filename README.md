# ARメジャー / AR Tape Measure

Measure real things with your phone camera. Tap point A and point B and see the length in cm/m or inches/feet. Measure several lines, undo, clear.

- Live: https://gutsmcd-cmd.github.io/ar-measure/
- Uses WebXR (`immersive-ar` + `hit-test`) — Chrome on Android with Google Play Services for AR.
- Free, no ads, no login. Works offline after the first visit (PWA).
- 日本語 / English toggle and a Large text switch.

Built with Vite + TypeScript + three.js. Deployed to the `gh-pages` branch by GitHub Actions.
